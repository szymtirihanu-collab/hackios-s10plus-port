# HackiOS S10+ — Restarted

**Status: Started over.** The previous project contents have been cleared from the `main` branch so the work can begin again from a clean baseline.

## Goal

Research the feasibility of running Apple's actual Darwin/iOS environment on the Samsung Galaxy S10+ (SM-G975F, beyond2lte, Exynos 9820).

This is a research project, not a claim that a working iOS port already exists.

## Working rules

- Establish the boot architecture and hardware requirements before implementation.
- Keep research, source changes, build outputs, and test evidence traceable.
- Never describe a build as working without reproducible test evidence.
- Do not flash unverified images or make experimental partition-table changes.
- Preserve known-good device firmware and a recovery path before any device-side testing.

## First milestone

Rebuild the project plan from verified upstream sources and exact-device hardware evidence, then define measurable boot milestones.
